# Jingles — estrutura multilíngue

- `pt-br/index.html`: página brasileira (nova).
- `es-ar/index.html`: página argentina migrada, preservando o conteúdo existente.
- `assets/css/site.css`: estilos compartilhados.
- `assets/`: áudios, capas e PDFs compartilhados.
- `index.html`: página original mantida como referência/compatibilidade; não foi substituída.
- `en-us/`: reservada para a futura página em inglês; ainda não publicada.

## Publicação
Copie as pastas `pt-br`, `es-ar` e `assets` para `/lp/jingles/` no servidor.
Não ative link para `en-us` até a página ficar pronta.
O WhatsApp está configurado nos HTMLs; revise o número antes da publicação.
A URL atual `/lp/jingles-showcase/` permanece independente; só redirecione quando decidir.
